# Effectus v0.6.2

Effectus v0.6.2 publishes the durable workflow and release-verification fixes in
[PR #85](https://github.com/josephjohncox/effectus/pull/85) and the gRPC update in
[PR #86](https://github.com/josephjohncox/effectus/pull/86).

## Changes

- New `DURABLE_FAIL_FAST` checked plans carry no inverse dispatch intent. After
  an unsuccessful execution, the runtime cancels later queued dispatches before
  recording a terminal state. Uncertain external outcomes remain blocked for
  reconciliation instead of being labeled as ordinary canceled work.
- Durable migration `10005_canceled_dispatch.sql` adds the `canceled` dispatch
  state and repairs stranded work on historical terminal executions while
  preserving attempt and effect evidence. Forward claims now respect serial
  order, and pruning no longer deletes a reactivated generation.
- The optional `ExecutionFinalizer` interface extends the durable store API
  without changing the `OutboxStore` contract. The compiler rejects retry
  backoffs outside Go's duration range. The plan-selection documentation now
  states that `.eff` list plans precede `.effx` flow plans.
- Publish and recovery now scan the pushed AMD64 and ARM64 image manifests and
  verify their evidence before final version tags or the GitHub release marker.
  CI runs the pinned Python gRPC client over plaintext and verified TLS; the
  Go-proxy compatibility smoke uses a cold module cache.
- `google.golang.org/grpc` moves from 1.83.2 to 1.84.0. The dependency audit
  has an exception only for GO-2026-6443 on this exact version: the
  [gRPC advisory](https://github.com/grpc/grpc-go/security/advisories/GHSA-2v4p-qf9q-27wj)
  lists 1.84.0 as patched, while the
  [Go database correction](https://github.com/golang/vulndb/pull/6580) is pending.

## Upgrade

Apply the complete durable schema with a DDL credential using
`--mode=migrate --database-migrations=apply` before starting new workers. Run
the daemon with a separate DML credential and
`--database-migrations=validate`. The down migration refuses to discard
`canceled` dispatches.

Stop independently operated generic outbox dispatchers for checked executions
admitted by older versions until those executions are terminal. Older saga
rows do not record the checked plan policy, so a generic worker could claim a
previously frozen fail-fast inverse before checked-runtime recovery blocks it.
The OCI registry must enforce version-tag immutability.

## Validation

[PR #85 CI](https://github.com/josephjohncox/effectus/pull/85/checks),
[PR #86 CI](https://github.com/josephjohncox/effectus/pull/86/checks), and
[merged-main CI](https://github.com/josephjohncox/effectus/actions/runs/36488349175)
passed. The tag-triggered [Publish run](https://github.com/josephjohncox/effectus/actions/runs/36490573028)
passed all 15 quality jobs but failed at the public Go-proxy smoke because its
cold module cache sat inside the scratch module; it did not create this release.
[PR #88](https://github.com/josephjohncox/effectus/pull/88) fixed the smoke
helper and recovery checkout order. The [recovery run](https://github.com/josephjohncox/effectus/actions/runs/36494101642)
verified tagged assets, checksums, signatures, OCI digests, and public Go-proxy
compatibility before creating this release. No protobuf or SQLC binding
regeneration was required.
