# Effectus v0.6.1

Effectus v0.6.1 publishes the dependency maintenance in
[PR #83](https://github.com/josephjohncox/effectus/pull/83).
It updates the PostgreSQL driver and the VS Code extension's development tools.

## Changes

- `github.com/jackc/pgx/v5` moves from 5.10.0 to 5.11.0.
- The extension packager `@vscode/vsce` moves from 3.9.2 to 4.0.0, and ESLint
  moves from 10.9.1 to 10.11.0. The lockfile was resolved and tested with both
  updates together.

This patch has no changes to Go implementation files, the public API, protobuf
definitions, or database migrations. The Go minimum remains 1.26, with the
repository pinned to Go 1.26.8. The extension remains declarative, requires
VS Code `^1.74.0`, and packages the same language configuration, grammar,
snippets, and icons. gRPC remains at the patched 1.83.2 version.

## Validation and artifacts

[PR CI](https://github.com/josephjohncox/effectus/actions/runs/36464710344),
[branch CI](https://github.com/josephjohncox/effectus/actions/runs/36464764309),
and [merged-main CI](https://github.com/josephjohncox/effectus/actions/runs/36465195141)
each passed all 15 jobs. These checks include PostgreSQL and Kafka integration,
race tests, Go and npm vulnerability audits, container scans, Node 22 extension
packaging, chart checks, and documentation contracts. Local checks also passed
for Go modules, vet, guardrails, `govulncheck`, `npm ci`, `npm audit`, tests, and
the ten-file VSIX package.

The release workflow reruns CI for this tag before publishing signed OCI
artifacts, CLI archives, the Helm chart, VSIX, source bundle, SBOMs, provenance,
and checksum and completion manifests. Publication also requires v0.3
compatibility imports to resolve through the public Go proxy.

The [runtime guarantees](../GUARANTEES.md) and
[production runbook](../PRODUCTION_RUNBOOK.md) remain the operational references.
Release and CI success do not establish deployed Kubernetes recovery or
representative production capacity.
